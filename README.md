# Todo List Application (Python)

## 📌 Description
This is a simple **console-based Todo List application** built using Python.  
It allows users to manage daily tasks by adding, viewing, and removing tasks through a menu-driven interface.

## 🛠 Features
- Add new tasks
- View all tasks with numbering
- Remove tasks by task number
- Simple and user-friendly console interface

## 💻 Technologies Used
- Python
- Lists
- Loops and Conditional Statements
